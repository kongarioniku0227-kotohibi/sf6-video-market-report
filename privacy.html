プライバシーポリシー

YouTube API サービスの利用

このツールは YouTube Data API v3 を使い、日本語のストリートファイター6動画を調査します。利用者には YouTube 利用規約 が適用されます。Google による情報の取り扱いは Google プライバシー ポリシー をご覧ください。

取得する情報と利用目的

公開動画のID、タイトル、説明、公開日時、尺、サムネイルURL、チャンネル名・ID、公開登録者数、再生数、高評価数、コメント数を取得します。検索語と調査日時を記録し、ジャンル別の集計、過去の観測との比較、動画企画の検討に使います。個々のコメント本文は取得しません。

通信先と保存先

調査時に検索条件、動画・チャンネルID、APIキーを Google の API に送信します。OAuth ログインは使用しません。結果は利用者の Windows PC 内の SQLite、CSV、HTML、Markdown に保存します。ダッシュボードがサムネイルを表示する際は配信元に接続し、IPアドレス等が伝わります。外部リンクを開くと、移動先のポリシーが適用されます。

保存期間と更新

タイトル、説明、チャンネル名などは取得から30日以内に更新または削除します。分析用途の適用が認められた場合、統計と派生指標の保存上限は1,094日です。期限処理はツール実行時に行います。運用者は期限までに再取得するか、期限到来時にレポート再生成を実行し、コピーした出力も管理します。

削除と問い合わせ

利用者はツールを終了し、プロジェクト内の data と reports の調査結果、別途保存したコピーを削除できます。APIキーは .env または環境変数から削除でき、Google Cloud の認証情報画面で無効化できます。共同利用者からの取り扱い・削除の問い合わせは、このツールを共有した運用者が共有時の連絡経路で受け付けます。
