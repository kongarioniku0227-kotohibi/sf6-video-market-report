スト6 動画市場レポート

ストリートファイター6の日本語動画を調べ、プロゲーマーの配信からどんな対戦や解説を切り出すか、編集企画を検討するためのツールです。開発者のPCで動作し、調査と集計にログインは不要です。

操作デモ

公開期間と動画形式を切り替え、ジャンルやタイトルで絞り込み、集計結果をCSVに保存するまでの26秒間をご覧いただけます。

デモの動画・チャンネル・数値はすべて架空です。動画ファイルを開く

調査に使用する情報

YouTube Data API v3で公開動画の再生数、公開日時、尺、公開チャンネル情報などを取得します。通常動画、Shorts、ライブを分けて集計し、分類根拠や標本数と一緒に表示します。
