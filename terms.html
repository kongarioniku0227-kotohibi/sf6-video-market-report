スト6 動画市場レポート

利用規約

利用目的

本ツールは、公開されたストリートファイター6関連動画を調査し、動画編集・企画の判断を支援するために、利用者のPC上で動作します。

YouTube API サービス

本ツールは YouTube Data API v3 を利用します。本ツールを利用する方は YouTube 利用規約 に拘束されることに同意するものとします。運用者は、対象プロジェクトで認められた用途・割り当ての範囲でデータを取得し、分析します。

データと分析結果の取り扱い

公開時点や取得時点により、件数や再生数は変化します。ジャンル分類、ランキング、企画案は本ツール独自の分析です。利用者は公開データと推定を区別し、素材を利用する際は動画、音声、サムネイルなどの権利と利用条件を確認してください。

保存・削除と認証情報

運用者はAPIキーを管理し、第三者への開示を避けてください。取得する項目、外部との通信、ローカルデータの保存期限・削除手順、問い合わせ方法は プライバシーポリシー に記載しています。Google による情報の取り扱いには Google プライバシー ポリシー が適用されます。
